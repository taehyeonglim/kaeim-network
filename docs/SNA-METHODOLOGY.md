# 공저 구조 분석: 계산·배치·해석 기준

분석 방법 버전: `sna-1`. 대상 데이터 버전: `e76251e3b2115b`. 공개 사이트의 ‘구조 분석’은 교육정보미디어연구에서 관찰된 공저 관계를 분석합니다. 회원 명부나 학회 전체의 모든 사회관계를 대표하지 않으며 전문성·우열 점수를 만들지 않습니다.

## 분석 범위와 필터

선택 기간에 논문을 게재한 모든 연구자 묶음을 포함합니다. 단독 저자와 고립 노드를 보존합니다. 분야·정책 과제·검색어는 논문을 찾아 그 저자들을 강조하며, 계산 대상 네트워크를 줄이지 않습니다. 협력집단·연결요소를 선택하면 강조 조건과 교차합니다. 표는 강조 대상부터 보여주지만 전체 기간망의 모든 노드를 유지합니다.

기존 ‘연구 탐색’에서는 기간·분야·검색이 논문과 연결을 필터링하는 동작을 그대로 유지합니다. 두 모드의 차이를 화면에 명시합니다. 구조 분석의 지표·비교·내보내기는 모두 선택 기간 전체망 기준입니다. 기간에 논문이 없는 선택 연구자는 ‘분석에 포함되지 않음’으로 표시합니다.

## 공저 가중치

논문의 중복 저자 ID를 제거한 후, 서로 다른 저자 쌍마다 하나의 무방향 관계를 만듭니다. 단일 저자 논문은 노드의 논문 수에 포함되지만 연결을 만들지 않습니다.

- 기본 `papers`: 저자 쌍이 함께 쓴 고유 논문 수.
- 보정 `fractional`: 각 공동 논문의 저자 수가 k일 때 쌍마다 1/(k−1)을 더함. 모든 공동 논문을 합산함.

보정은 다인 공저 논문의 쌍별 기여를 줄이는 모델상의 선택입니다. 실제 협력 시간·친밀도를 측정한 값이 아닙니다. 두 방식은 노드와 연결의 존재 여부를 바꾸지 않습니다. 연결강도·매개중심성·협력집단·배치는 선택한 가중치에 따라 달라질 수 있습니다.

## 지표

| 지표 | 계산 |
|---|---|
| 논문 수 | 선택 기간에 참여한 고유 논문 수 |
| 공동연구자 수 | 직접 연결된 서로 다른 연구자 묶음의 수 k |
| 연결중심성 | k/(N−1), N<2이면 0 |
| 연결강도 | 해당 노드의 연결 가중치 합 |
| 매개중심성 | 연결 길이=1/가중치인 최단경로에서 해당 노드가 내부에 놓이는 비율의 합, 무방향 정규화 |
| 다른 집단의 공동연구자 | 다른 탐지 집단에 속한 직접 공저 상대 수 |
| 밀도 | 2E/[N(N−1)], N<2이면 0 |

매개중심성은 Graphology의 가중 Brandes 구현으로 전수 계산합니다. 순서 없는 노드 쌍을 기준으로 쓴 식은 `2/[(N−1)(N−2)] × Σ σ_st(v)/σ_st`입니다. 끝점은 제외하며, 도달할 수 없는 쌍은 기여하지 않습니다. N<3이면 0입니다. 정규화의 N은 연결요소별 크기가 아닌 선택 기간 전체 노드 수이며, 기간별 값을 단순한 성장률로 해석하지 않습니다. 계산에서 쓰는 연결 길이와 화면상 점 사이 거리는 별개입니다.

작은 양수의 매개중심성은 0으로 반올림해 숨기지 않고 지수 표기로 표시합니다. 파일에는 반올림 전 값을 저장합니다.

## 협력집단과 연결요소

가중 Louvain, 해상도 1, `sna-1:0`부터 `sna-1:9`까지의 고정 난수 시드 10개를 사용합니다. 각 후보의 집단 내부가 단절되어 있으면 연결요소별로 분리하고 모듈러리티를 다시 계산합니다. 최종 모듈러리티가 가장 높은 결과를 사용하며 1e−12 이내 동률은 앞선 시드로 결정합니다. 고립 노드는 집단에 배정하지 않습니다.

연결요소·협력집단은 구성원 수 내림차순, 동률은 최소 연구자 ID 순으로 번호를 붙입니다. 같은 입력에서 재현되지만 다른 기간·가중치에서 같은 번호나 색이 같은 집단이라는 뜻은 아닙니다. ‘협력집단’은 공식 조직·연구팀의 확인이 아닙니다. 대표 연구분야는 집단의 고유 논문 집합에서 분야별 논문 수를 세어 표시합니다.

모듈러리티는 분할 평가값이며 통계적 유의성이나 신뢰확률이 아닙니다. 특히 여러 연결요소로 나뉜 네트워크에서는 높은 값 자체를 강한 사회적 응집력의 증거로 해석하지 않습니다. 시드별 모듈러리티와 분할 서명은 계산 기준 JSON에 보존합니다. 집단 간 직접 연결과 최단경로 매개 역할은 별도로 제공합니다.

## 지도 배치와 시각 부호

전체 기간 위치 유지가 기본입니다. 선택한 가중치의 전체 기간망으로 구한 좌표에 기간 내 노드·연결을 표시합니다. 선택 기간 재배치는 해당 기간 전체망의 좌표를 다시 계산합니다. 검색 강조·색·점 크기는 계산한 좌표를 변경하지 않습니다.

- 2D: ForceAtlas2 1,000회. 정렬된 ID, 고정 시드 초기 좌표, 가중치 반영, Barnes–Hut 활성화, gravity 0.7, scalingRatio 7, slowDown 5, strongGravityMode 활성화.
- 3D: d3-force-3d 600회. 고정 초기조건·난수, 목표 연결 거리 `24 / weight^0.15`, 연결 힘 0.6, 반발력 −18, 축별 중심화 0.025, 충돌 반경 2.2. 최대 원점 거리 230으로 균일 정규화.
- 점 크기: 논문 수 / 공동연구자 수 / 매개중심성. 2D는 면적, 3D는 부피에 값을 선형 반영하되 0도 보이도록 최소 크기를 둡니다. 현재 네트워크의 최댓값으로 표시 범위를 정하므로 서로 다른 기간의 픽셀 크기를 절대량처럼 비교하지 않습니다.
- 색상: 탐지 협력집단 / 기간 내 주된 연구분야. 고립 노드는 협력집단 색상에서 회색입니다. 그룹 목록과 상세에서 집단 ID를 확인할 수 있습니다.
- 선 굵기: 선택 가중치를 제곱근으로 완화하고 표시 상한을 둡니다. 상세와 내보내기는 정확한 수치를 제공합니다.

유한 반복 배치는 유일한 정답이나 수렴 보장이 아닙니다. 화면 중앙·높이·거리·색상을 영향력, 친밀도, 통계적 집단 확정으로 읽지 않습니다.

## 민감도 검사와 실제 결과

재현: `npm run audit:sna`. 상세: [sna-audit.json](sna-audit.json).

전체망에서 두 가중치 각각 기본 설정, 반복 횟수 두 배, 다른 초기조건을 비교했습니다. 기본 이웃 보존율은 2D 약 0.519–0.526, 3D 약 0.478–0.509입니다. 이 값은 각 비고립 노드의 실제 이웃 수만큼 가까운 점을 찾았을 때 실제 이웃과 겹치는 비율의 평균입니다.

최대 연결요소에서 결정적으로 선택한 최대 4,000쌍의 기하학적 거리 상관을 측정했습니다. 2D는 반복 횟수를 두 배로 늘리면 약 0.956–0.986, 초기 시드를 바꾸면 약 0.268–0.421입니다. 이는 초기 배치가 거시적 모양에 영향을 준다는 근거입니다. 3D의 다른 초기조건 검사는 기본 좌표에 축별 0–10의 변위를 주고 난수 시드도 바꿉니다. 해당 변화에서 거리 상관은 약 0.987–0.992였습니다. 이 제한된 검사로 모든 초기조건에서의 안정성을 보장하지 않습니다.

전체망의 기본 가중치에서 연결요소는 172개, 고립 노드는 78개, 최대 연결요소는 895개 묶음(67.60%)입니다. 탐지 집단은 논문 수 가중치 115개, 보정 가중치 114개입니다. 10개 시드의 분할은 각각 10종·9종으로 달라졌습니다. 탐지 집단의 유일성이나 소속 신뢰확률을 주장하지 않습니다.

## 실행·캐시·파일

계산은 Web Worker에서 실행합니다. 기간·가중치·배치 변경 시 이전 Worker를 종료하고 요청 ID 및 화면 요청 키를 확인해 오래된 결과를 버립니다. 데이터 버전·방법 버전·기간·가중치별로 결과와 좌표를 캐시하며, 각 캐시는 최근 삽입 20개까지 유지합니다. 전체 기간의 두 가중치 결과 및 2D·3D 좌표는 `npm run data:sna`로 미리 생성합니다. 누락·버전 불일치 시 브라우저 Worker로 다시 계산합니다.

CSV와 GEXF는 강조 조건과 무관하게 선택 기간 전체망을 내보냅니다. 연구자 ID·식별 상태·지표·집단·연결요소, 연결의 실제 공동 논문 수·보정 가중치·선택 가중치·분석상 거리·근거 논문 ID를 포함합니다. 데이터 버전·기간·가중치·방법 버전은 CSV 열과 GEXF 속성에 기록합니다. 계산 기준 JSON에는 공식·요약·시드별 진단도 포함합니다. 빈 결과 CSV는 헤더만 가지며 가짜 데이터 행을 만들지 않습니다.

GEXF는 선택 기간망의 노드·연결·분석 속성을 제공하며 화면의 표시 크기·카메라 상태는 포함하지 않습니다. 사용자 확인·보류·미검토 상태를 유지하고, 분석 중 추가 동일인 통합을 수행하지 않습니다. 원본 메타데이터·논문 간 인용 관계·기존 결측 범위도 변경하지 않습니다.
