# 데이터와 해석 기준

## 범위와 기준일

메타데이터는 2026-11-13 수집·교정 스냅샷이며, KCI 논문 ID 목록은 2026-11-15에 확인했습니다. 1,168편은 KCI 1,076편, 초기 RISS/KISS 82편, 2002년 보충 KISS 10편입니다. 원본 파일의 해시는 생성 보고서에 남깁니다.

확보된 발행연도는 1996–2026년입니다. 창간호·1995년·1997년 미확인 자료가 있어 완전한 전수 자료로 해석하지 않습니다. 참고문헌 39,407건은 서로 다른 참고문헌 수가 아닌 논문별 등장 기록 수입니다. 참고문헌을 확보한 논문은 901편이며 2004–2025년에 분포합니다. 2026년의 참고문헌 미확보는 인용이 없다는 뜻이 아닙니다.

초록 PDF 원문 대조를 재개하지 않았습니다. 기존 원문 불일치와 교정 범위의 한계는 상위 프로젝트의 검증 문서에 보존됩니다. 웹의 분류는 그 저장된 텍스트를 사용한 별도 추론입니다.

## 연구자 식별

저자 등장 기록은 `논문 ID#1부터 시작하는 저자 순번`입니다. 이름과 논문 당시 소속을 정규화한 뒤 임시 묶음을 생성합니다. 한국어 공백·영문 대소문자를 정규화하고, 명시한 대학 약칭만 확장합니다. 영문 이름은 알파벳 토큰을 정렬·결합해 순서·하이픈 차이를 줄입니다.

같은 이름·소속에서 서로 다른 영문 정규화 값이 나타나면 별도 묶음으로 나눕니다. 이름이나 소속이 비면 각 등장 기록을 별도로 유지합니다. 이렇게 생성한 1,679개 기본 묶음에 사용자 확인 판단을 적용한 결과는 1,324개 묶음입니다. 실인원 또는 학회 회원 수가 아닙니다. 같은 사람이 여러 소속·표기로 나뉘거나, 동일 이름·소속을 공유하는 사람들이 묶였을 가능성이 남아 있습니다. 사용자 확인 320묶음, 판단 보류 81묶음, 미검토 임시 923묶음을 구분해 표시합니다.

근거 있는 교정은 `identity-overrides.json`의 assignments에서 등장 기록별로 `{researcherId, evidence}`를 지정합니다. 소속 이동이나 공저자 유사성만으로 자동 병합하지 않습니다. 현재 소속·직위 중 사용자가 제공한 정보는 논문 당시 소속과 별도 필드로 저장하고 사용자 확인이라고 표시합니다. 외부 공식 자료 검증이나 회원 자격 확인을 의미하지 않습니다.

`config/identity-review.json`에는 295개 이름에 대한 통합·분리·보류 판단과 해당 기본 그룹 ID, 저자 등장 ID를 보존합니다. `scripts/identity_review.py`가 명시된 통합만 적용하고 서로 다른 사람으로 확인된 관계와 보류 그룹의 병합을 거부합니다. 보류는 33개 이름의 81개 묶음으로, 다른 사람으로 확정한 것과 다릅니다. `applied: true`는 보류 상태 유지까지 포함한 사이트 반영 여부입니다.

이름 교정(임병로→임병노)과 소속 교정(강명희·임현진·정옥년)은 지정한 기록에만 적용하며 논문 상세 JSON에 원래 표기를 남깁니다. 원본 DB는 변경하지 않습니다. 통합된 이전 프로필 ID 355개는 대표 ID로 연결하여 기존 공유 링크를 유지합니다. 공저 연결과 2D·3D 배치는 통합 이후 다시 계산합니다.

## 집계

| 항목 | 기준 |
|---|---|
| 연구자의 논문 수 | 선택된 논문 중 해당 연구자 묶음이 등장하는 고유 논문 수 |
| 공저 연결 | 같은 논문의 서로 다른 연구자 묶음 쌍. 가중치는 고유 공동 논문 수 |
| 공동연구자 수 | 선택된 공저 연결의 서로 다른 상대 묶음 수 |
| KCI 누적 피인용 | 선택된 논문에서 KCI 값이 확보된 항목의 합. 확보 편수/대상 편수를 함께 표시 |
| 내부 인용 | 보유 논문 사이의 고유 방향성 연결. 출발점=인용한 논문, 도착점=인용된 논문 |
| 연구자 내부 피인용 | 선택된 해당 연구자의 논문을 인용하는 보유 DB 전체의 고유 논문 연결 수 |

공동 논문은 각 저자에게 1편으로 집계하므로 저자별 합은 전체 논문 수와 일치하지 않습니다. 공동저자들이 동일 논문에서 받은 KCI 피인용 수도 서로 겹치므로 연구자 합계를 학회 총합으로 표시하지 않습니다. 자기인용은 포함합니다. 종합 점수·전문성 점수·우열 순위는 만들지 않습니다.

인용 매칭은 참고문헌의 KCI 논문 ID를 우선하며, 없을 때 정규화 DOI가 보유 논문 한 편과 유일하게 일치하면 연결합니다. ID와 DOI가 충돌하면 제외하고 보고합니다. 같은 출발·도착 쌍은 한 연결로 묶으며 근거 reference ID는 모두 보존합니다. 현 스냅샷은 ID 기반 1,260개 연결이며 추가 DOI 연결과 충돌은 없습니다. 제목 유사 매칭은 사용하지 않습니다.

기간·분야·검색 필터는 우선 논문 집합에 적용합니다. 인용 지도는 그 집합의 논문이 인용한 대상들을 표시하며, 필터 밖 대상은 회색 문맥 노드로 남깁니다. 상세 논문의 인용 목록은 필터와 관계없이 DB 전체에서 보여줍니다. 미확보 KCI 값과 참고문헌 수는 null이며, 화면에 ‘미확보’로 표시합니다.

## 분류와 근거

학술 10분야와 정책·현장 6과제의 다중 태깅입니다. 제목·원문 키워드에 해당 규칙이 있으면 학술 분류를 부여합니다. 초록에만 나오는 학술 분류는 서로 다른 규칙 2개 이상을 요구합니다. 정책 과제는 별도의 구체적 표현 규칙을 적용합니다. 규칙·출처 필드·원문 발췌를 논문 상세에 저장하며 원문 키워드와 서비스 추론 태그를 구분합니다.

규칙 기반 분류는 전문가 확정 분류가 아닙니다. 문맥에 따른 오탐·누락이 남을 수 있습니다. 미분류를 허용하며, 여러 분야가 붙은 논문은 각 분야에 계산됩니다. 분류별 개수의 합은 논문 수보다 클 수 있습니다. 분야를 연구자에게 직접 추정하지 않고 연결된 논문에서 집계합니다.

초기 샘플 검토에서 `AI`가 training 등의 일부로 매칭되거나 `e learning`이 mobile learning의 일부로 매칭되는 문제를 수정했습니다. 교사·교육공학자가 면접 참여자라는 이유만으로 ‘교원 역량’에 연결되는 규칙도 좁혔습니다. 관련 회귀 검사를 유지합니다. 분류 근거 추적 가능성은 모든 공개 태그에서 자동 검사하지만, 모든 태그의 의미를 사람이 전수 검증했다는 뜻은 아닙니다.

## 지도 표현과 접근성

공저 지도는 ForceAtlas2의 사전 계산 좌표, 분야 지도는 주된 분야 주변의 결정적 위치, 인용 지도는 논문 인용 관계의 사전 계산 좌표를 사용합니다. 공저 점 크기는 논문 수의 제곱근, 선 굵기는 공저 수의 제곱근으로 완화하고 정확한 값은 상세에 표시합니다. 분야 점 크기는 연구자의 관련 논문 수, 인용 점 크기는 현재 화면에서 들어오는 내부 인용 연결 수입니다.

색은 현재 선택 조건에서 가장 많은 논문이 연결된 학술 분야이며, 동률은 분야 ID 순입니다. 거리는 전문성·친밀도·평가 점수가 아닙니다. 고립 노드를 유지하며 선택·호버 시 주변 연결만 강조합니다. 목록 보기는 같은 필터의 연구자·논문에 키보드로 접근하는 대안이고, WebGL 실패 시 목록 전환을 제공합니다. 단, 보조 기술별 전수 호환성을 검증한 것은 아닙니다.

### 3D 보기

공저·인용 지도는 d3-force-3d의 결정적 초기 배치에서 관계 기반 시뮬레이션 420회를 미리 계산합니다. 축별 값을 평가 점수나 지리적 위치로 해석하지 않습니다. 브라우저에서는 좌표를 고정하고 카메라만 회전·확대하므로, 필터를 바꿔도 같은 연구자·논문의 기준 위치가 유지됩니다.

분야 지도는 10개 분야의 중심점을 입체 공간에 고르게 배치하고 연구자 묶음을 현재 조건의 주된 분야 주변에 배치합니다. 중심 주변의 세부 위치는 ID 기반으로 일정하게 생성한 표시용 좌표입니다. 모든 해당 분야에 연결하며, 이 선은 공저 관계가 아니라 분야 소속 관계입니다. 미분류 연구자는 중앙에 남깁니다.

연구자 구의 부피는 관련 논문 수에 비례하며, 인용 지도는 현재 내부 피인용 수에 기본 부피 1을 더합니다. 분야 중심 구는 구분용 크기로 고정합니다. 3D 색상은 동일한 분야 색에 밝기를 보정한 것입니다. 선택 시 관련 연결을 강조하고 이름은 선택·호버·근접 조건에서 최대 12개만 표시합니다. 표시를 제한해도 데이터나 집계에서 노드를 제거하지 않습니다.

3D는 기존과 동일한 논문 집합·공저 가중치·인용 방향을 사용합니다. 3D용 데이터 모델은 독립적인 복사본을 만들므로 렌더러의 좌표·연결 객체 변경이 원본 공개 스냅샷에 영향을 주지 않습니다. 기본 2D를 유지하고, 3D 표시가 어려우면 2D 및 목록으로 탐색할 수 있습니다.

## 공개 산출물과 운영

정적 앱은 공개용 요약 JSON과 논문별 상세 JSON만 로딩합니다. API 키, 원본 XML, PDF, 내부 검증 파일 경로는 공개 산출물에 포함하지 않습니다. 지도 데이터는 브라우저에서 처리하고 별도 분석·추적 서비스를 사용하지 않습니다. 검색어를 포함한 현재 상태는 공유 URL에 담깁니다.

원본 갱신 → 공개 데이터 재생성 → 데이터 검사 → 화면 검사 → 빌드 → GitHub main 푸시 및 Pages 자동 배포 순서로 운영합니다. 데이터/분류 규칙 해시와 버전을 보존하며 자동 수집·예약 배포는 설정하지 않습니다.
