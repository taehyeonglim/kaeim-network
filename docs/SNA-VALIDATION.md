## 계산의 독립 검증

작은 경로·별·삼각형·단절 그래프와 여러 6노드 사례에서 모든 단순 경로를 열거하여 가중 최단경로와 매개중심성을 별도로 계산했습니다. 서비스의 Brandes 결과와 1e−9 허용오차로 비교합니다. 공저 가중치와 보정 가중치, 동일 저자 ID 중복 제거, 단독 저자, 작은 N의 정규화도 검사했습니다.

선택 집단은 내부가 연결되어 있고 모든 비고립 노드를 정확히 한 번 포함합니다. 같은 입력과 시드의 결과가 재현되며, 기록한 후보 중 최고 모듈러리티 결과를 선택합니다. 파일 내보내기의 한글·따옴표·수식 시작 문자를 검사하고 GEXF를 다시 읽어 노드·연결·지표·식별 상태·근거 논문 ID를 대조했습니다. 빈 CSV에는 헤더만 있습니다.

## 성능과 배치 진단

로컬 Chrome의 배포용 빌드에서 캐시하지 않은 2018–2026년 분석은 146ms, 기간별 2D·3D 재배치는 3,319ms였습니다. 특정 장비에서 측정한 결과이며 모든 기기의 성능 보장은 아닙니다. 전체 기간의 두 가중치 분석과 좌표는 사전 계산되어 있습니다.

반복 횟수 및 초기조건 민감도는 `npm run audit:sna`로 검사했습니다. 2D의 거시적 모양은 초기조건에 민감했고, 협력집단도 시드별로 일부 달랐습니다. 해당 한계는 화면과 [계산 기준](SNA-METHODOLOGY.md)에 명시합니다. 기능 검증을 알고리즘의 유일성·수렴·통계적 유의성 검증으로 해석하지 않습니다.
