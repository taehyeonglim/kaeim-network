# KAEIM 몰입형 지식 관측소

2026-11-15. 기존 공개 GitHub Pages 앱의 디자인·상호작용 개편 기록입니다.

## 구현

- 실제 네트워크를 화면 중심에 두고 큰 소개 영역과 고정 3단 패널을 제거했습니다. 공식 로고, 상단 검색·탐색 목적 전환, 하단 보기·기간 요약·조건 버튼을 배치했습니다.
- `ObservatoryWorkspace`가 두 경험의 패널을 관리합니다. 데스크톱은 비모달 드로어, 760px 이하에서는 한 개의 모달 하단 시트로 표시합니다. Escape·닫기·초점 순환·이전 초점 복귀, 선택 변경 시 상세 스크롤 초기화를 지원합니다.
- 상세 닫기는 선택 해제가 아닙니다. 선택을 유지한 채 지도 공간을 되찾고 ‘선택 상세’로 다시 열 수 있습니다. 상세 내부의 선택 해제는 기존처럼 선택 자체를 제거합니다.
- 분석 지표 설정, 협력집단·연결요소 목록, 전체망 다운로드와 방법 설명은 ‘분석 도구’에 있습니다. 기간·강조 조건·가중치는 ‘분석 조건’에 있습니다.
- 남색 `#07111F`, 패널 `#101E33`, 본문 `#EEF4FC`, 보조 글자 `#A6B8CE`, 선택 강조 `#75D9F5`를 사용합니다. 원본 분야 색은 표시 시 밝게 변환하고 2D·3D·범례에 같은 변환을 적용합니다. 협력집단은 기존의 결정적 색상 순서를 유지하며 밝기를 높였습니다.
- 선택 시 청색 외곽선·라벨과 직접 연결을 강조합니다. 관련 없는 라벨은 숨깁니다. 배경 장식용 가짜 노드·연결은 없습니다.
- 2D 캔버스는 ResizeObserver로 패널·기기 크기를 추적합니다. 노드 표시 크기는 화면에 맞춰 동일 비율로 조정하며 지표의 비율을 보존합니다. 3D 카메라는 크기 변경에 맞춰 다시 맞춥니다.

## 호환과 데이터

- 데스크톱 새 진입: 연구 탐색 3D. 구조 분석 첫 전환: 2D. 모바일·embed 새 진입: 2D.
- 기존 해시가 있는 URL에서 `dim`이 없으면 2D라는 기존 의미를 유지합니다. 명시한 3D는 모바일에서도 복원합니다. 새 공유 주소는 양쪽 차원을 모두 명시합니다.
- 탐색/분석별 차원 선택은 메모리에 유지합니다. 전체 새로고침 시에는 공유 URL에 명시된 현재 보기로 복원합니다. 패널 열림 상태는 URL에 넣지 않습니다.
- 원본·공개 데이터, 동일인 판단, 연구자 ID 리디렉션, SNA 계산, 가중치, 좌표, CSV/GEXF/JSON 형식을 변경하지 않았습니다. 데이터 버전은 `e76251e3b2115b`입니다.
- 노드 위치는 분석 좌표이며 거리·높이는 우열이나 실제 지리적 위치가 아닙니다. 독립 테스트 서비스와 확보 범위 설명을 유지합니다.
- 자동 회전·점멸은 없습니다. 동작 감소 설정에서는 패널 애니메이션과 카메라 이동 시간을 제거합니다. 3D 로딩 실패는 2D로, 2D 표시 실패는 목록/표로 전환할 수 있습니다.

## 검증

- `npm test`: 공개 데이터·검색·동일인 링크·3D 토폴로지·독립 SNA 중심성·가중치·내보내기, 30개.
- `npm run test:source`: 원본 해시·기록 보존과 동일인 판단 가드, 15개.
- `npm run build`: TypeScript와 프로덕션 번들. 기존 Three.js 3D 번들의 크기 경고는 남아 있으며 분리된 청크로 필요한 보기에서 로드합니다.
- 브라우저: 탐색 13개, 3D 9개, 동일인 8개, SNA 15개, 관측소 12개. 결과는 `browser-*-qa.json`에 기록합니다.
- 새 관측소 검사는 공식 이미지 로딩, 모드별 차원 기억, 옛 주소, 패널 스크롤·선택 유지·캔버스 크기 동기화, 키보드 초점, 모달 전환, 모바일/태블릿/짧은 데스크톱/임베드, 동작 감소, 기본 글자색 대비를 포함합니다.
- 시각 검수: 1440×1000, 1280×720, 820×1180, 390×844, 1000×760 embed. 지도·프로필·논문 근거·분석 도구·하단 시트의 스크린샷은 상위 `tmp/atlas-qa/`에 있습니다.

## 출처와 배포

공식 로고 및 참고 포스터 출처는 [브랜드 자산 기록](../public/brand/README.md)에 있습니다. 기존 `main` → GitHub Actions → GitHub Pages 배포 경로를 사용합니다. 기존 Sites 식별자는 변경하지 않습니다.

공개 GitHub Pages에서도 관측소 12개 시나리오를 통과했습니다. [배포 주소 검사 결과](browser-observatory-live-qa.json). 반응형 패널의 모달 전환 검사는 미디어 쿼리 이벤트 처리 완료를 기다린 후 판정합니다.
