## 파비콘과 홈 화면 아이콘

`npm run brand:icons`로 공식 로고의 왼쪽 심벌 영역을 SVG 뷰포트에 배치해 렌더링합니다. 검정·흰색과 심벌의 비율을 유지하며, 원본 PNG를 수정하거나 로고를 새로 그리지 않습니다. 공식 로고의 자세한 글자는 작은 탭 아이콘에서는 생략 없이 축소되어 표시됩니다.

- `favicon.ico`: 실제 16·32·48px 이미지가 들어 있는 다중 해상도 ICO
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`: 브라우저용 PNG
- `apple-touch-icon.png`: 180px, 흰색 불투명 배경
- `icon-192.png`, `icon-512.png`: 홈 화면용 PNG
- `site.webmanifest`: GitHub Pages 하위 경로에서 동작하는 상대 URL, 브라우저 표시 모드

아이콘 링크에 `v=1`을 명시합니다. 차기 변경 시 링크 버전을 함께 올려 이전 파비콘 캐시와 구분합니다. 매니페스트는 아이콘·표시 정보를 제공하며 오프라인 앱이나 서비스 워커를 추가하지 않습니다.
