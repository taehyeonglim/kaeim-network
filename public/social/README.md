# 소셜 공유 이미지

- 파일: `kaeim-research-atlas-v1.png`
- 규격: 1200 × 630px PNG
- 작성일: 2026-11-15
- 기반: 공식 KAEIM 로고와 공개 데이터 `e76251e3b2115b`의 공저망(1,324개 연구자 묶음, 2,456개 연결)
- 제작: HTML/SVG 브랜드 레이아웃을 Chromium으로 렌더링. 실제 저장된 3D 좌표를 평면 투영하며 가짜 연결을 추가하지 않습니다. 이미지 생성 모델을 사용하지 않습니다.
- 재생성: 로컬 Chrome이 설치된 환경에서 `npm run social:image`. 한글 글꼴은 Noto Sans KR / Apple SD Gothic Neo / 시스템 글꼴 순서이며 운영체제에 따라 글꼴 차이가 있을 수 있습니다.
- 로고 원본 출처: [브랜드 자산 기록](../brand/README.md)

`index.html`에 Open Graph와 Twitter 대형 카드 메타태그를 정적으로 제공합니다. 공유 크롤러는 JavaScript 실행 없이 이미지 URL·제목·설명을 읽을 수 있습니다. 모든 프로필·필터 공유 링크는 공통 사이트 썸네일을 사용합니다. 추후 이미지를 교체할 때는 파일명 버전과 양쪽 이미지 메타태그를 함께 갱신합니다.
